- **開始日**: 2026-08-12
- **カテゴリ**: 開発
- **状態**: 進行中（第1〜第3フェーズ完成・動作確認済み）

## 目的
太陽を中心とした8惑星の現在位置をリアルタイムで見られるスマホアプリ。
第2フェーズで中心天体の切替（地球中心＝見かけの空）と暦パネル、
第3フェーズで七十二候・生年月日入力・生年月日からの人物理解機能を追加した。

### 生成物（すべて生成物。直接編集しないこと）

| 形態 | 生成物 | 用途 | 特徴 |

## PWA（第4フェーズ）

### 相対パス設計 — ホスティング先が未定でも動く
配信先がルートでもサブパスでも同じ dist/ がそのまま動くよう、**すべて相対パス**にしてある。

- manifest: `start_url: "./"`、`scope: "./"`
- head: `<link rel="manifest" href="./manifest.webmanifest">` など
- SW登録: `navigator.serviceWorker.register('./sw.js')`
- SW内のアセット参照: `new URL('./index.html', self.location)` で解決

`make-pwa.js` は出力前に、絶対パス参照（`/` 始まりや `http://` 始まり）が
混ざっていないか検査して落ちる。

### アイコン
`src/mkicon.js` が依存ライブラリなしで生成する（PNGエンコーダも自前）。

| ファイル | 用途 |
|---|---|
| `icons/icon-192.png` | manifest `purpose: "any"` |
| `icons/icon-512.png` | manifest `purpose: "any"` |
| `icons/icon-maskable-512.png` | manifest `purpose: "maskable"`。**別デザイン** |
| `icons/apple-touch-icon.png` | iOS ホーム画面（iOSはmanifestを見ないので別途必要） |

maskable は図柄を `k=0.78` に縮めて中央80%の円（セーフゾーン）に収め、
背景は角まで塗りつぶしてある。`any` を流用すると角が切られる。
生成時に「図柄の最外周 = 半径0.782 ≤ 上限0.80」を検査し、超えたら落ちる。

### dist/ と docs/ の関係
`docs/` が GitHub Pages の公開ディレクトリで、git 管理下にある
（`dist/` と `solar-system.artifact.html` は `.gitignore` 済み）。

**`make-pwa.js` は dist/ を作ったあと docs/ へ自動で同期する。**
手作業のコピーに頼ると、修正がビルドされていても公開版に届かないまま
放置される事故が起きるため（実際に一度その状態になった）。
`docs/.nojekyll` は同期時に消さず残す。

### Service Worker のキャッシュ更新の仕組み
ここを間違えると更新が二度と届かなくなるので、仕組みを明記しておく。

1. `make-pwa.js` が **index.html・manifest・全アイコンの中身**から SHA-256 を取り、
   先頭12桁を `VERSION` として `sw.js` に埋める。キャッシュ名は `solar-<VERSION>`
2. どれか1バイトでも変われば VERSION が変わり、`sw.js` 自体の中身も変わる。
   ブラウザは `sw.js` のバイト差分で更新を検知する
3. `install` で全アセットをプリキャッシュする。**`skipWaiting` は呼ばない**
   （黙って入れ替えず、本人に選ばせる）
4. 新しい SW が `waiting` になったらページ側が**更新バナー**を出す。
   「再読み込み」で `postMessage({type:'SKIP_WAITING'})` → `controllerchange` → `location.reload()`
5. 新しい SW の `activate` で、接頭辞 `solar-` が同じで名前の違う
   **古いキャッシュをすべて削除**してから `clients.claim()`

補足:
- 初回インストール時は `controllerchange` で再読み込みしない（`hadController` で更新と区別）。
  リロードループを防ぐため
- `controllerchange` が来ない環境向けに 2.5秒のタイムアウト保険がある
- `file://` では SW を登録できないので、失敗しても握りつぶして通常動作を続ける
  （単一ファイル版の導線を壊さないため）
- SW は**同一オリジンの GET しか扱わない**。外部通信は一切しない
- ナビゲーションはオフライン時に `index.html` へフォールバックする
- プッシュ通知・バックグラウンド同期は入れていない（このアプリに不要）

## 決定済み事項

**覆さない前提。ここに書いてあることは再検討しない。**

### 全体
- 単一HTMLファイル。**外部通信ゼロ・ライブラリ不使用**。build.js がこれを機械的に検査して落とす
- 3D視点は作らない。黄道面を上から見た2Dのみ
- 冥王星・小惑星帯・衛星は入れない（月だけ第2フェーズで例外的に追加）

### 惑星位置
- JPL / E.M.Standish の平均軌道要素＋ケプラー方程式のニュートン法解
- TAB1（1800–2050）と TAB2（3000BC–3000AD、b,c,s,f 補正項つき）を併用。境界手前8年でクロスフェード

### 縮尺・中心天体
- 実スケール ⇄ 見やすいスケール（対数圧縮 `ln(1+r/0.16)`）を補間で切替
- 中心天体の切替は**原点の平行移動方式**で確定（ホロスコープ式の円周配置は作らない）
- 中心が太陽以外のとき、黄道帯リングと見かけの軌跡（逆行ループ）を出す

### 暦
- すべて**日本時間（JST, UTC+9）基準**。日付境界はJST深夜0時
- 太陽の視黄経は Meeus 第25章（精度 約0.01°）、月は Meeus 第47章（誤差 約10秒角）
- ΔT は Espenak & Meeus (2006)

## ★ 50音歴の定義（将来の再現に必須）

**冬至（太陽黄経270°）を起点とし、太陽黄経が 7.2° 進むごとに次の音へ移る定気法。**
360 ÷ 50 ＝ 7.2 なので、必ず冬至でちょうど一巡して1番目に戻る。

```
ホ オ ヲ ヘ エ ヱ フ ウ ゥ ヒ
ミ イ 井 ハ ア ワ ヤ ィ ユ ェ
ヨ ノ ネ ヌ ニ ナ ラ リ ル レ
ロ コ ソ ケ セ ク ス キ カ シ
サ タ チ ツ テ ト モ メ ム マ
```

1番目「ホ」が冬至から始まる区間。**「井」は「ヰ」に正規化しない。**
実体は `src/calendar-core.js` の `GOJUON` と `GOJUON_STEP`。

**各音に意味・属性・対応表は一切持たせていない。音と日付だけを出す。**
ここはユーザーの領域。**この方針は変更しないこと。**

## ★ 七十二候の系統（第3フェーズ）

**日本の「本朝七十二候」（明治7年・略本暦の系統）を採用。**
中国の宣明暦系（元の七十二候）とは名称が異なる。**両者を混ぜていない。**
UIの七十二候セクションにもこの旨を明記してある。

- 二十四節気を3等分し、**太陽黄経5°ごとに1候**。72候で一巡
- 第1候＝立春初候（黄経315°）。実体は `calendar-core.js` の `KOU`（漢文表記／読み／現代語の意味）

## ★ 二十七宿・宿曜道の方式（第3フェーズで方針変更）

指示書 birth-cycle-reflection 4.4 に従い、**伝統暦方式と天文方式を混ぜない**。

### 人物理解機能での本命宿 ＝ 伝統暦方式（正）
```
本命宿 =（旧暦月の朔日宿 + 旧暦日 − 1）mod 27
朔日宿表: 1月=室 2月=奎 3月=胃 4月=畢 5月=参 6月=鬼
          7月=張 8月=角 9月=氐 10月=心 11月=斗 12月=虚
27宿の並び: 昴 畢 觜 参 井 鬼 柳 星 張 翼 軫 角 亢 氐 房 心 尾 箕
            斗 女 虚 危 室 壁 奎 婁 胃
```
**閏月の扱い**: 直前の通常月と同じ朔日宿を使う（閏6月なら6月の朔日宿＝鬼）。

### 暦パネルの二十七宿 ＝ 天文方式（比較資料）
ラヒリのアヤナムシャによる恒星黄経・恒星黄経0°＝婁宿起点。2026年で約24.225°。
`NAKSHATRA_CONFIG`（`ayanamsha` と `startIndex`）1か所で切替可能。`ayanamsha: 0` で回帰黄道。

**両方式は別モデルなので結果は一致しない。** 1000例で **97.9%が不一致**（後述）。
人物理解機能では伝統暦方式を正とし、天文方式は「比較資料」と明記した別枠に降格させている。

## ★ 人物理解機能の設計原則（第3フェーズ・最重要）

指示書 `~/.claude/skills/birth-cycle-reflection/` が仕様の正本。要点:

- **占いアプリではない。検証可能な仮説を生成する道具**
- 主従の固定: **本人の生命・履歴・環境・選択・行動が躰＝主**、暦記号・星・宿・解釈文が用＝従
- 生年月日から見えない本質・未来・魂の目的を**断定しない**
- 全項目に `[計算] [伝統] [仮説] [確認] [反証] [不能]` のタグチップを付ける
- **的中率・確率・スコア・パーセンテージを一切出さない**（読みの中では月の輝面比の％も出さない）
- 死・病気・事故・犯罪・妊娠出産・離婚・財産を予測しない。採用・信用・医療・法律の判断へ誘導しない
- 「欠けている要素」を欠陥と書かない。「内的に自動化されにくく、環境・技能・他者から補える可能性」と書く
- 性別・ジェンダーは**呼称の選択と本人が確認する文脈の質問にしか使わない**。男女別大運順逆は既定で使わない
- 反対仮説と確認質問が無い仮説は出さない。確認質問は「いつ・どこで・誰と・何をしたか」で答えられる形
- **status を本人が画面上で切り替えられる**（未検証／本人が支持／反証あり／混合）。反証を消さずに残す

### 採用した流派・表・境界（四柱推命）
| 項目 | 採用 |
|---|---|
| 年柱の境界 | **立春の瞬間** |
| 月柱の境界 | **十二節**（立春・啓蟄・清明・立夏・芒種・小暑・立秋・白露・寒露・立冬・大雪・小寒）。旧暦月は使わない |
| 日柱の写像 | `(JDN + 49) mod 60`。JDN は JST の暦日 |
| 時柱 | 出生時刻がある場合のみ。23:00〜23:59 は子刻だが日柱は繰り上げない（**夜子時を採らない**） |
| 蔵干表 | 本気・中気・余気の三分表（子=癸／丑=己癸辛／寅=甲丙戊／卯=乙／辰=戊乙癸／巳=丙庚戊／午=丁己／未=己丁乙／申=庚壬戊／酉=辛／戌=戊辛丁／亥=壬甲） |
| 五虎遁・五鼠遁 | 標準。年干→寅月干、日干→子刻干 |

### 算命学：`[不能]` にした箇所（捏造しなかった部分）
- **人体星図の配置**（頭・胸・腹・左手・右手・肩・足のどこにどの星が入るか）
  → 流派ごとの配置表を確信をもって固定できなかったため、**配置は一切出していない**。
     星そのもの（十大主星・十二大従星）は算出して出している
- **大運の順逆（進む向き）** → 旧来の男女二分法を前提とする流派規則のため既定では使わない

採用した部分: 十大主星は十神の再命名として写像（貫索星=比肩／石門星=劫財／鳳閣星=食神／
調舒星=傷官／禄存星=偏財／司禄星=正財／車騎星=偏官／牽牛星=正官／龍高星=偏印／玉堂星=正印）。
十二大従星は十二運から写像。天中殺は「一旬に現れない二支」という**算術事実のみ**を `[計算]` とし、
「天が欠ける」「不運」は `[伝統]` として分離。吉凶判定には使わない。

### 出生時刻の入力UI（第5フェーズで変更）
`<input type="time">` は**使わない**。OSの時計ピッカーが開くが、確定の作法が
端末ごとに違って（iOSは確定ボタンがなく枠外タップ、Androidは文字盤のOKが見つけにくい）
実機で「確定できずに詰まる」報告があったため。

代わりに「時」「分」の2つの `<select>` にしてある。
- 時 = 0〜23、分 = 0〜59。**分は1分刻みで全部出す**（節入り境界の判定に効くので間引かない）
- 両方の先頭が「— 時（不明）」「— 分（不明）」で、**これが既定**。
  未選択のままなら今までどおり時刻不明として扱い、時柱・真太陽時・節入り境界を出さない
- 選択中の値は常に下に文字で出す（`出生時刻: 09:30` / `出生時刻: 未入力（時柱は出しません）`）

**片方だけ選ばれた場合は、足りない側を0で埋めずに先へ進ませない。**
「時と分の両方を選んでください」と警告を出し、足りない側にフォーカスする。
`09時` だけ選んだ人が `09:00` 生まれとは限らず、0で埋めるのは推測値の生成にあたるため。
このアプリは推測値を作らないことを最優先にしている。

`<input type="date">` はそのまま。日付は選ぶと即座に欄へ反映されて値が常に見えており、
時計ピッカーのような「確定できたか分からない」状態にならないため。
年月日を3つのselectにすると年の選択肢が200件近くになり、かえって扱いにくい。

時刻が不明のまま誕生時へ移動した場合、図の表示には便宜的に正午を使うが、
バッジは「**誕生日（時刻不明・正午で表示）**」と出して、正午を出生時刻と
誤解させないようにしている（時刻が分かっている場合は「誕生時」）。

### タップ設計の判断（記録）
惑星タップは**中心切替を優先**。情報パネルは画面の約6割を覆うため、切替と同時に開くと
「いま見たかった切替後の図」が隠れる。情報は ⓘ か「もう一度タップ」に逃がした。

### 誕生時ロックの仕組み
`pinnedMs` が非nullの間は端末時計を追いかけない。1倍速ならその瞬間で静止し、
倍速にすればそこから動き出す。バッジは紫の「誕生時」。「今」ボタンで解除。

### プライバシー
生年月日は端末外に出ない（アプリは一切通信しない）。localStorageへの保存は
**既定オフのオプトイン**。「保存された入力を削除」ボタンあり。動作確認済み。
